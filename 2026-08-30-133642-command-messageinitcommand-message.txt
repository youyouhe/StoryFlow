  🐛 真实 Bug

  1. tsc 不可用 / 类型检查缺位 — node_modules 未安装，且 package.json 没有
  lint/typecheck script。CI 和开发时都没有类型守护。

  2. Gemini 模型名写死且可疑 (geminiService.ts:78)
  model: 'gemini-3-flash-preview',
  gemini-3-flash-preview 不是公开可用模型，且硬编码无法在设置里改（DeepSeek 有
  deepseekModel 字段，Gemini 没有对应字段）。应该改为可配置，默认用
  gemini-2.0-flash 之类的稳定模型。

  3. AI 续写插入位置错误 (App.tsx:583-587)
  acceptAISuggestion 把续写内容插在当前选中 block 之后。但"续写"的语义通常是"接
  着文末往下写"，选中块可能在文档中间，导致续写插到中间。更合理是插到 blocks
  末尾，或至少插在最后一个非空块后。

  4. sepia 主题是死类型 (types.ts:41)
  Theme 含 'sepia'，但 App.tsx 的 theme state 是 'light' | 
  'dark'，没有任何切换入口，sepia 永远用不到。类型与实现不一致。

  5. 分页估算与实际 DOM 不一致 (pagination.ts)
  estimateBlockHeight 用固定的 CHARS_PER_LINE=60、lineHeight=27 像素估算，但
  EditorBlock 用 md:text-[1.05rem]、leading-relaxed、不同 w-2/3/w-3/4
  宽度限制。实际换行宽度和估算差别很大，分页断点会不准。这是 PDF
  打印和阅读视图页码不准的根源。

  ⚠️ 较重要的问题

  6. acceptAISuggestion 对 IDEAS 模式处理不当
  IDEAS 返回的是创意建议（本该展示给用户参考），但 acceptAISuggestion
  会把它当作剧本块按行解析插入正文。用户点"插入"会把建议文本插进剧本。建议 IDEAS
  模式禁用"插入"按钮，或改为复制到剪贴板。

  7. localStorage 存 API Key 明文 (App.tsx:189, geminiService)
  appSettings 含 geminiApiKey/deepseekApiKey，整体序列化进 localStorage。Tauri
  桌面端尤其应考虑用 keychain/安全存储。

  8. PDF 导出错误时 window.location.reload() (App.tsx:343)
  导出失败直接刷新整个页面，会丢失未保存的编辑（虽然 autosave

  算法 (adaptColorForTheme)

  1. light 主题 → 原色直接返回，不动。
  2. dark 主题 → hex → HSL：
    - 提亮：l = min(75, l + max(15, (80-l)*0.5))，颜色越暗提得越多。
    - 降饱和：s = max(40, s-10)，避免在黑底上出现霓虹刺眼感。
    - 对比度兜底：用 WCAG 相对亮度算候选色与深色纸张(#18181b)的对比比，若 <
  4.5（正文级阈值）就继续抬 l，直到达标或封顶 90。
  3. 空值 → 原样返回，回落到 Tailwind 的 dark:text-*
  主题类（这些本身已正确处理明暗）。
  4. 非 hex（如 rgb()/transparent）→ 原样返回，不强行解析。

  "一份提示词"的实现

  用户要"对 character 的文生图提示词保留一份"——剧本里同一个角色名会出现在多个
  CHARACTER 块（每次该角色说话都有一行）。保存时，以当前块的 
  content（角色名）为键，把 prompt 写到所有同名 CHARACTER 块。这样：
  - 在任意一处该角色的 CHARACTER 块生成提示词 → 全部同名块都带上同一份
  - 后续在任何一处重新生成 → 整体更新，仍只保留一份
  - 卡片在每个 CHARACTER 块下都可见，但内容一致

  匹配规则是 b.content.trim() === charName（CHARACTER
  块本身就是大写角色名）。这覆盖了"同一角色多次出场"的去重需求。

  验证方式

  dev server 仍在后台跑（端口 3000），刷新浏览器：
  1. 写一条 CHARACTER 块（如 HERO），定位其上按 Alt+S →
  生成人物设计图提示词（Subject 会描述外貌）
  2. 保存 → 该块下方出现卡片
  3. 在剧本别处再写一个 HERO 的 CHARACTER 块 → 它也自动带上同一份提示词
  4. 选中非 ACTION/CHARACTER 块按 Alt+S → 提示"请选中动作块或角色块"
