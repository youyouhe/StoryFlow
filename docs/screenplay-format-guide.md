# 剧本格式指南

> issue #14 配套 · 提取清洗规则的用户侧说明
> 原则:**怎么写都提取得动**——下面的建议让提取产物(角色 ref/场景短键/TTS 文本)更干净;违规不阻断,提取器自动清洗并在 IR 面板给出警告级提示。

## CHARACTER 块 = 纯角色名

```
✅ 登山者
✅ 陆之白
⚠️ 登山者（喘息）     ← 可写:括注被视为表演提示,提取时自动剥离
```

- 角色名**尾部**的 `（…）`/`(…)` 括注是**表演提示**(喘息/微笑/愣住…),提取时剥离——`登山者（喘息）` 与 `登山者` 解析为**同一角色**(`char:登山者`),括注内容归入所在镜头的表演描述(motionPrompt)。
- 例外:若资产库为该角色登记了**同名变体设定图**(如 `苏晚/晨雾围巾`),括注仍解析为换装变体(`char:苏晚:晨雾围巾`)——变体是"换装",不是"表演"。
- 冒号是 ref 键保留字,角色名里请不要用冒号(会被替换为下划线)。

## SCENE_HEADING = 地点短语优先

```
✅ 内. 茶馆 - 夜
✅ 悬崖攀岩壁
⚠️ 暴雨夜，悬崖攀岩壁，闪电劈开乌云。   ← 可写:自动取首个地点短语作短键
```

- 场景 ref 的**绑定键**是清洗后的短键:剥内外景前缀(`内./INT.`)与尾标点,按「，,、-」切段后取首个**地点**短语(纯时间/天气的短段如「暴雨夜」「黄昏」被跳过)。
- **完整标题保留**在该场景 ref 的 `description` 里,导出/提示词不受短键影响。
- 短键是绑定键——同一场戏的标题写法保持一致,避免"改一字即失配"。

## DIALOGUE = 首尾不要手工加引号

```
✅ 还有十米。
⚠️ “还有十米。”   ← 可写:提取时自动剥离首尾引号
```

- 首尾的 `“”`/`""`/`「」`/`『』` 引号在进入音频轨与字幕轨时**自动剥离**——TTS 朗读引号会产生怪顿,字幕也不需要。
- **正文内**的标点与引号(人物引用别人的话)原样保留。
- 台词归拍规则:对白属于它上方的 ACTION 镜头;镜头切换(新场景标题/新 ACTION)前的对白归上一镜。

## 其他口径

- **时间戳前缀**(`00:00-00:03。`)是 AI 生成剧本的拍点;手写剧本没有也行——提取自动按朗读估时合成节拍(逐拍标 `estimated`,面板会提示)。
- **画外音/旁白**:cue 写 `角色名（画外）` 或 `(V.O.)`——会解析为独立 delivery 字段,该角色不会被生成进画面。
- 体检警告在 **导出菜单 → IR pipeline** 面板顶部实时显示(警告级,永不阻断)。
